# 🔐 Password Security Tool

A beginner-friendly Python project that checks password strength and generates random strong passwords.

## ✨ Features

- Check password strength
- Generate random passwords
- Supports uppercase and lowercase letters
- Supports numbers
- Supports special characters
- Simple command-line interface

## 🧠 Concepts Used

- Python functions
- Loops
- Conditional statements
- `random` module
- `string` module
- String validation

## ▶️ How to Run

```bash
python password_security.py
